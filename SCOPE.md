# Scope

This repo is the set of skills I actually use. It is curated: ideas are welcome, and each one is judged against the bar below.

## The bar

An issue stays open only if it:

1. **Describes an observed failure**: what you ran, what the skill did, what you expected. Hypothetical improvements don't clear this.
2. **Fits the philosophy**: small, composable, harness-neutral skills. Personal config tweaks belong in your own `CLAUDE.md` / `AGENTS.md`, or a fork.

Questions and discussion go to GitHub Discussions.
